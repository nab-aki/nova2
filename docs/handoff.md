## 3. 未解決の点

**ToF（スプリント3.6。正本は common_tof_checklist.md）**

- **【未確認】Car Board に挿した状態で、GPIO26・27 に配線できる場所があるか**（ユーザーが実物で確かめる）。
- **【未確認】Pololu #3419 の端子の並び・プルアップの有無・LPn の扱い**（届いてから確かめる）。
- **【見積もり】初期化は約2〜3秒（400kHz）**。計算による値で、実測ではない。ライブラリは実機では未確認。
- **【未対応】ライブラリの `IO_Read` の永久ループ2か所**（センサーが応答しないと loop が止まる）。組み込みの前に直す。
  lib/ に取り込むときは、THIRD_PARTY_NOTICES.md にも足す。

**ID16 に引き継ぐ点（2026-10-12。コードの読み取りは measurements.md「調べたこと：有効な測定が0回の向きの扱い」）**

- **見回しで有効な測定が0回の向きは、値が 80cm（`ULTRASONIC_MAX_CM`）のままになる**（`NeckScan`）。
  - ID25 の見回し：有効な回数を見ずに 80cm として比べる＝「空いている」。
  - ID15 の左右確認：有効な回数は見るが、測れた側が 50cm 未満なら測れなかった側へ回る（今回の困る 1)：左 30.3cm／右 有効0/3 → 右へ）。
  - ID15 の測り直し：5回とも測れなければ「空いた」（今回の困る 2) の回転1：有効0回で空いた。設計どおり）。
  - 浅い角度の壁は反射が戻らないので、接触の原因の候補の一つ（確かめてはいない）。「測れず」を「空いている」と分けるかを決める。
- **時間の上限（600ms）で止まった回転が6回あった**（74回中。今までは 0回）。18.6°・39.9° しか回っていない回がある。
  止まってはおらず、ゆっくり回っていた。原因は未確認（満充電）。回ったつもりの角度と実際がずれる前提で設計する。
- **気づいて止まったときの距離が 12cm より近い件は未解決のまま**（今回の最小 3.5cm。下の「動きの観察」）。
- 最初の首振りは約10回に1回遅れる。**「最初の向きは失敗しうる」を条件に入れる。**

**首・見回し**

- **【既知の限界・対策なし】最初の首振りが約10回に1回、約0.5秒遅れる**（上の「現在地」）。
  左右を測ったつもりで正面の値が入るので、ID25・ID15 の向きの判断を誤ることがある。
- **【未実施】サーボの交換**：交換用のサーボは手元にない。入手したら、交換して再現するかを確かめる。
- **【未解決・原因未確定】明らかに前方に障害物がないのに、向きを変えることがある**（2026-10-10 に気づいた。候補は 25_wander.md「見回しが途中で終わる経路」）。
  第一の候補は ID25 の向き変え（横が 40cm 未満なら、正面が空いていても 50° 回る。設計どおり）。首の遅れが効いている可能性もある。
- **浅い角度の壁への接触**：ID25 の向き変えを 50° にしても、目視で約4回（30°のときは5回程度）。ほとんど減っていない。対策はスプリント3.6（ToF）と ID16。
- **【未確認】PCA9685 の反映のタイミング**：周期の途中で書いたときの扱いは、データシートの文章からは確認できなかった（図10・11 を目で見る必要がある）。
  MODE2 の OCH は既定（STOP で反映）のはずだが、実機では読んでいない。首の件の原因からは外れたので、急がない（common_neck.md）。
- **【仮】のしきい値**（試験の記録だけに使う）：`DEBUG_SCAN_ONSET_DPS` 2.0dps、`DEBUG_SCAN_TILT_ONSET_DPS` 1.0dps。

**ジャイロ（スプリント3.5）**

- **【仮】のしきい値**：ゼロ点補正の平均 ±5dps、回り始め・止まったの判定（回転の記録用）。
- 惰性は指示が大きいほど大きい（30°の指示で 7〜13°、50°で 11〜16°、ID26 で 22°）。引く分は固定の 10° なので、大きい指示ほど回りすぎる（意図どおり。調整しない）。
- ジャイロが使えないときの時間ベースは、今の電池では設計より大きく回る（600ms で約80°の見積もり）。
- **【未確認】FIFO のまとめ読み**：複数件を1回の通信で読めるかはデータシートで確認できず、1件ずつ読んでいる。バスの占有が問題になったら調べる。
- **【未実施】PCA9685 の OE ピンの配線の確認**（common_gyro_checklist.md）。
- 加速度は動かしていない。段差での空回りの検知は、あとで考える。

**電源・電池**

- **【未対応】電池ボックスのリード線が細い**（AWG24以下と思われる。README に記載）。AWG18 以上へ交換を推奨しているが未交換。
  回り始めに電池が 8.2V → 5.4〜5.9V まで落ちる（リセットはしていない）。ブラウンアウトが出たら配線の径を最初に疑う。

  回る速さは 2026-10-04（約80dps）と 10-10（約150dps）で大きく違う。原因は未確定（電池の充電状態が候補）。
  前進・後退の最低PWM（`MOTOR_PWM_MIN` 675／650）は旧タイヤで測った値のまま。
- **【未対応】NiMH 電池へ切り替えた日付が記録されていない。**
