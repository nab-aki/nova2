**第1段階の実機確認の結果（2026-10-10。数字は measurements.md「ジャイロ第1段階の実機確認」）**

- 確定：`GYRO_YAW_SIGN`＝+1／ゼロ点補正の「動いた」判定 1.0dps／取り付け位置（左前）／J5・J6 開放のまま（decisions.md）。
- 静止：標準偏差 Z0.019dps、角度のずれ -0.12°/分。モーター動作中でも Z の標準偏差 0.683dps（PWM2000 回転）、飛び・頭打ち 0。
- 回転：425ms で約 50°、1170ms で約 160°、止めたあとの惰性 約9°（6.6〜11.3°）。10/04 の約1.5〜1.8倍で、原因は未確定（電池の充電状態が候補）。
  回り始めの電池は 8.2〜8.35V → 最低 5.6〜5.9V まで落ちるが、リセットなし。
- ケーブルなし5分37秒（午後）：I2C の失敗 0、飛び 103件（約18件/分）、loop を止めた時間 最大 18.03ms。
  425ms で 42〜67°（設計 30°）、1534ms で 220°（設計 118°）。**時間ベースは今、設計の約1.5〜1.9倍回っている。**

**電源・電池**

- **【未対応】電池ボックスのリード線が細い**（AWG24以下と思われる。README に記載）。AWG18 以上へ交換を推奨しているが未交換。
  旋回の PWM を 2000 に上げたので、電流が増えた分ブラウンアウトの要因になりうる。出たら配線の径を最初に疑う。
