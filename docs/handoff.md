## 1. 現在地：スプリント3.5（ジャイロ搭載）。残りは、30° に戻したあとの5分うろうろだけ

- 実装順（正本は catalog.md）：9 → 25 → 26 → **3.5 ジャイロ** → 16 → 18 → 15 → 6 → 21 → 4。スプリント3（ID26）までは完了。
- **いま Nova に入っているのは本体（fnk0053、既定のビルド）のコミット `efc737f`**（2026-10-11 に COM4 で書き込み。
  起動ログで、サーボの割り当て 左右＝ch0・上下＝ch1、ジャイロと PCA9685 の初期化の成功を確認済み）。
  - **サーボのコネクタは、書き込みの時点で両方とも基板から抜いてあった。** 次に動かす前に、元の端子（左右＝ch0、上下＝ch1）に
    戻してあるかを確かめる（電池のスイッチを切って挿す）。
- **その場回転は、ジャイロの角度で止める**（2026-10-10。仕様は docs/specs/common_gyro_turn.md。値は確定、完了条件は満たした）。
  - 指示する角度：ID15 は 30°、ID25 の向き変え・後退+その場回転は 50°、ID26 は 60〜120°／150〜210°、キー 3・4 は 30°、7・8 は 90°。
  - **ID15 を 30° に戻したあとの5分うろうろは、まだ行っていない。**
- **首が動かない回の調査は、2026-10-11 に中断した**（結論と根拠は docs/specs/common_neck.md「結論と方針」、数字は measurements.md）。
  - 現象：正面でしばらく止まったあとの最初の首振りが、約10回に1回（240回中24回）、約0.5秒遅れる。
  - 原因は左右のサーボ自体（ケーブルを含む）にほぼ絞れた。ソフトでは直せない。**対策は入れず、既知の限界として先へ進む。**
  - うろうろへの影響：最初に見る向きの値が正面の値になる。正面の安全は別に見ているので、危険は増えない。
- ジャイロ（LSM6DSV16X）は Car Board の左前に固定済み。J3 短絡（0x6A）、J5・J6 は開放のまま。当面は**満充電で動作させる**前提。
- デバッグ機能（使い方は notes.md 2章）：見回しの試験 `o`・`i`（順番が逆）・`u`（上下も動かす）、実験用の `k`（上下の書き込みを省く）、
  チャンネルを入れ替えたビルド（環境 `fnk0053_swap`）。切り分けの道具として残してある。

## 2. 次にやること（順番）

1. サーボのコネクタが元の端子に戻っているかを確かめる（上の「現在地」）。
2. 満充電・ケーブルなしで5分うろうろ → 「回り続ける」が出ないか、壁に浅い角度で当たる回数、動きの印象を見る → 止めて `t`。
3. 問題がなければ、スプリント3.5 を完了にする（catalog.md の状態を更新）。
4. そのあとは ID16「見回し探索」（キー `o` の試験を土台にする）。**設計の条件に「最初の向きは失敗しうる」を入れる。**

## 3. 未解決の点

**首・見回し**

- **【既知の限界・対策なし】最初の首振りが約10回に1回、約0.5秒遅れる**（上の「現在地」）。
  左右を測ったつもりで正面の値が入るので、ID25・ID15 の向きの判断を誤ることがある。
- **【未実施】サーボの交換**：交換用のサーボは手元にない。入手したら、交換して再現するかを確かめる。
- **【未解決・原因未確定】明らかに前方に障害物がないのに、向きを変えることがある**（2026-10-10 に気づいた。候補は 25_wander.md「見回しが途中で終わる経路」）。
  第一の候補は ID25 の向き変え（横が 40cm 未満なら、正面が空いていても 50° 回る。設計どおり）。首の遅れが効いている可能性もある。
- **【未確認】浅い角度の壁への接触**：ID25 の向き変えを 50° にした効果は、まだ比べられていない（50° の試験は約3分で中止した）。
- **【未確認】PCA9685 の反映のタイミング**：周期の途中で書いたときの扱いは、データシートの文章からは確認できなかった（図10・11 を目で見る必要がある）。
  MODE2 の OCH は既定（STOP で反映）のはずだが、実機では読んでいない。首の件の原因からは外れたので、急がない（common_neck.md）。
- **【仮】のしきい値**（試験の記録だけに使う）：`DEBUG_SCAN_ONSET_DPS` 2.0dps、`DEBUG_SCAN_TILT_ONSET_DPS` 1.0dps。

**ジャイロ（スプリント3.5）**

- **【仮】のしきい値**：ゼロ点補正の平均 ±5dps、回り始め・止まったの判定（回転の記録用）。
- 惰性は指示が大きいほど大きい（30°の指示で 7〜13°、50°で 11〜16°、ID26 で 22°）。引く分は固定の 10° なので、大きい指示ほど回りすぎる（意図どおり。調整しない）。
- ジャイロが使えないときの時間ベースは、今の電池では設計より大きく回る（600ms で約80°の見積もり）。
- **【未確認】FIFO のまとめ読み**：複数件を1回の通信で読めるかはデータシートで確認できず、1件ずつ読んでいる。バスの占有が問題になったら調べる。
- **【未実施】PCA9685 の OE ピンの配線の確認**（common_gyro_checklist.md）。
- 加速度は動かしていない。段差での空回りの検知は、あとで考える。

**電源・電池**

- **【未対応】電池ボックスのリード線が細い**（AWG24以下と思われる。README に記載）。AWG18 以上へ交換を推奨しているが未交換。
  回り始めに電池が 8.2V → 5.4〜5.9V まで落ちる（リセットはしていない）。ブラウンアウトが出たら配線の径を最初に疑う。
