## 2. 次にやること（順番）

1. **実機確認（ケーブルあり）**。結果のログを受け取り、measurements.md に記録する。
   1. 床に置き、起動ログを見る：`[ジャイロ]` の行で WHO_AM_I＝0x70、読み戻しが「書いたとおり」、ODR、「ゼロ点補正 完了」。
   2. 床に置いて触らず、`m`（静止測定60秒）。
   3. **電池のスイッチを入れてから**、回転の確認：**床に印を付けて `3` を12回押し、一周したときの合計角度と符号を見る**
      （分度器より、ずれがはっきり分かる）。`4` `7` `8` も数回。**回転中は USB ケーブルを軽く持ち、車体を引っ張らないようにする。**
      `3`（左）で角度が正なら、`GYRO_YAW_SIGN` は今のままでよい。
   4. **電池のスイッチを入れたまま**、車輪を浮かせ、前を30cm以上あけて `n`（約31秒）。
   - 電池のスイッチを忘れると USB 給電だけになり、モーターが回らない（ユーザーの補足：10/7 のログは電池 1.04V で、USB 給電だけだった）。
   - 最後に `t`：I2C の失敗、1回の読み取りで loop を止めた時間（平均・最大）を見る。
2. **実機確認（満充電・ケーブルなし）**：5分うろうろ → 止めて `t`（I2C の失敗、回転の記録、動きが以前どおりか）。
   そのあとケーブルありで、もう一度 `m`（温まったあとのゼロ点を比べる）。
   モニタを開くと本体がリセットされて `t` の累計が消える。リセットせずに開く方法は notes.md 2章。
3. 結果を見て決める：`GYRO_YAW_SIGN`、【仮】のしきい値（config.h の `GYRO_*`）、取り付け位置を見直すか
   （モーター停止中と回転中のノイズの差）、J5・J6 を開放のままでよいか。
4. 第2段階：角度制御へ切り替える（時間ベースの値は予備・上限として残す）。
   完了条件は「90°の指示で±10°以内に10回中9回」（catalog.md）。
5. スプリント3.5 のあとは ID16「見回し探索」。

## 3. 未解決の点

**ジャイロ（スプリント3.5）**

- **【未確認】実機で確かめること**：回転の符号（`GYRO_YAW_SIGN` は +1 の見込み）／±500dps の換算（読み戻しと、実際に回した角度）／
  1回の読み取りで loop を止める時間（計算上 約4ms。止める瞬間と重なると回転が最大 約4ms＝約0.3° 長くなる）。
- **【仮】のしきい値**：ゼロ点補正の「動いた」判定（振れ幅 1.0dps・平均 ±5dps）、飛びの判定（100dps、区間内は標準偏差の8倍）、
  回り始め・止まったの判定。実機のノイズを見て決める。
- **【未確認】FIFO のまとめ読み**：複数件を1回の通信で読めるかはデータシートで確認できず、1件ずつ読んでいる。
  バスの占有（計算上 約13%）が問題になったら調べる。
- **【保留】J5・J6（SDX・SCX を GND へつなぐ）を短絡していない**（2026-10-07 判断）。
  見直すきっかけ：静止時のゼロ点のずれ・ノイズが想定より大きい／値が時々飛ぶ（`m` の結果で判断。理由は decisions.md）。
- **【未確認】取り付け位置（左前）で、モーターの振動を拾いすぎないか**（`n` の結果で判断。差が大きければ位置を見直す）。
- **【未実施】PCA9685 の OE ピンの配線の確認**（common_gyro_checklist.md）。
- 加速度は動かしていない。遠心分（計算上 約0.02g）の実測と、段差での空回りの検知は、第2段階以降。

**電源・電池**

- **【未対応】電池ボックスのリード線が細い**（AWG24以下と思われる。README に記載）。AWG18 以上へ交換を推奨しているが未交換。
  旋回の PWM を 2000 に上げたので、電流が増えた分ブラウンアウトの要因になりうる。出たら配線の径を最初に疑う。
- **【未確認】低電圧時の余裕**：回り出す最低PWMの測定と余裕の計算は行っていない（満充電が前提）。
  前進・後退の最低PWM（`MOTOR_PWM_MIN` 675／650）は旧タイヤで測った値のまま（再測定していない。動作は確認できている）。
- **【未対応】NiMH 電池へ切り替えた日付が記録されていない。** 旧タイヤ時代の測定と電池の変化を切り分けるために、分かれば記録する。
