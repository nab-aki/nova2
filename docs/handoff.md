## 1. 現在地：スプリント3.5（ジャイロ搭載）。角度で止める回転は動いている。首が動かない回がある件を切り分け中

- 実装順（正本は catalog.md）：9 → 25 → 26 → **3.5 ジャイロ** → 16 → 18 → 15 → 6 → 21 → 4。スプリント3（ID26）までは完了。
- **いま Nova に入っているのは本体（fnk0053）のコミット `4d6cc49`**（2026-10-10 に COM4 で書き込み。起動後の動作は未確認）。
  見回しの試験（キー `o`）にサーボの読み戻しが付いている。うろうろの動きは `bf56533` と同じ。
- **その場回転は、ジャイロの角度で止める**（2026-10-10。仕様は docs/specs/common_gyro_turn.md）。
  - 方針：回転は厳密に制御しない。安全の枠だけを守る（目標 − 固定 10° で止める。回っていない検知 300ms・3°、時間の上限、
    ジャイロが使えないときは時間ベース）。値は確定。完了条件（90°の指示で 60〜120°、押さえたら止まる、I2C の失敗が `t` に出る）は満たした。
  - 指示する角度：ID15 は 30°、ID25 の向き変え・後退+その場回転は 50°、ID26 は 60〜120°／150〜210°、キー 3・4 は 30°、7・8 は 90°。
    時間の上限（ジャイロが使えないときの時間）は `TROUBLE_TURN_STEP_MS` 600ms と、角度 × 13.0ms。
  - ID15 を 50° にすると、1周で約6方向しか見ず、空きを見つけにくかった（あきらめ2回）ので、30° に戻した。
    **30° に戻したあとの5分うろうろは、まだ行っていない。**
- **首が動かない回がある**（2026-10-10 夜、キー `o`、2abc33d）：見回し20回（首への指示60回）のうち4回（左3・右1）で、左右の値が正面と同じになった。
  打ち切りは 0、ログは「動かした」「安定」のまま。目視でも首が振らない回があった。以前からあった「見回しで片方しか向かずに動き出す」の原因と考える。
  コード上、書き込みが省かれる・別の値に変わる経路は見つかっていない（common_neck.md「首が動かない回がある」）。
- ジャイロ（LSM6DSV16X）は Car Board の左前に固定済み。J3 短絡（0x6A）、J5・J6 は開放のまま。当面は**満充電で動作させる**前提。
- デバッグ機能（使い方は notes.md 2章）：`t` に「回転の止め方」の回数と、ID15 の直近3回分の経過の記録が出る。`o` は止まったまま見回しを20回。

## 2. 次にやること（順番）

1. **読み戻しつきの見回しの試験**（書き込み済み）。ケーブルあり・一時停止中で `o`：
   首が振らない回を目で数え、まとめの「サーボの読み戻し」の不一致の回数と比べる。
   - 不一致がある → 指示が IC に正しく届いていない（ソフトか通信）。
   - 全部一致なのに首が動かない回がある → IC より先（サーボの電源、サーボ自体、配線）。
2. 結果で対策を決める。候補は common_neck.md（見回しの間、左右の角度を毎 loop 書き直す／読み戻して違えば書き直す／正面と同じ値なら測り直す）。
3. 満充電・ケーブルなしで5分うろうろ → 「回り続ける」が出ないか、壁に浅い角度で当たる回数、動きの印象を見る → 止めて `t`。
4. 問題がなくなったら、スプリント3.5 を完了にする（catalog.md の状態を更新）。そのあとは ID16「見回し探索」（キー `o` の試験を土台にする）。

**ジャイロ（スプリント3.5）**

- **【仮】のしきい値**：ゼロ点補正の平均 ±5dps、回り始め・止まったの判定（回転の記録用）。
- 惰性は指示が大きいほど大きい（30°の指示で 7〜13°、50°で 11〜16°、ID26 で 22°）。引く分は固定の 10° なので、大きい指示ほど回りすぎる（意図どおり。調整しない）。
- ジャイロが使えないときの時間ベースは、今の電池では設計より大きく回る（600ms で約80°の見積もり）。
- loop を止めた時間の最大（約17〜18ms）と飛びの原因は、追わないことにした（decisions.md 2026-10-10）。
- **【未確認】FIFO のまとめ読み**：複数件を1回の通信で読めるかはデータシートで確認できず、1件ずつ読んでいる。バスの占有が問題になったら調べる。

- 加速度は動かしていない。段差での空回りの検知は、あとで考える。
