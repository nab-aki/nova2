# 共通部品：ジャイロの角度で止めるその場回転（スプリント3.5 第2段階。v1・緩い版）

ID には紐づかない共通部品（#0）。その場回転を、時間ではなくジャイロで測った角度で止める。
時間ベースの値は消さず、予備と上限として残す。

- 状態：**仕様を緩い版に書き直した（2026-10-10）。書き込み1・書き込み2とも未実装。**
- 方針（2026-10-10 変更。decisions.md）：**回転を厳密には制御しない。安全の枠だけを守る。**
  Nova の目的は生き物らしくうろうろすることで、回転に数度の精度は要らない。ある程度のばらつきは残す。
  現段階ではシンプルな制御を優先する。
- 先に読むもの：[common_gyro_checklist.md](common_gyro_checklist.md)（第1段階の実装）、
  measurements.md「ジャイロ第1段階の実機確認」（2026-10-10 の午前・午後）。

## 目的

- 電池の状態や床で、回る量が大きく変わらないようにする。今の時間ベースは、設計の約1.5〜1.9倍回っている
  （2026-10-10 の実測。425ms で 42〜67°、1170ms で 143〜173°、1534ms で 220°）。
- 回らないとき・ジャイロが使えないときに、必ず止まる。

## 対象と対象外

| | 内容 |
|---|---|
| 対象 | その場回転（`TURN_ROTATE_LEFT`／`TURN_ROTATE_RIGHT`）。ID15・ID25・ID26・デバッグキー 3・4・7・8 |
| 対象外 | 片側旋回（`TURN_PIVOT_*`。キー 5・6。今は振る舞いで使っていない。時間ベースのまま） |
| 対象外 | n キー（モーターの振動の測定。車輪を浮かせて10秒回す。時間で回すまま） |

ジャイロのレジスタ操作・読み方（120Hz・±500dps・25ms ごとに FIFO を読む）は、第1段階から変えない。

## 止め方

```
止める角度 ＝ 目標角度 − GYRO_TURN_COAST_DEG（10°。固定）
```

- 回し始めてから回った角度（ジャイロの向きの積算の差）が、止める角度に届いたらモーターを止める。
- 10° は、止めたあとに惰性で回る分（実測 6.2〜13.1°）。**固定値で、調整しない。**
  回る速さや電池で惰性は変わるが、そのばらつきは残す。
- 回る出力は今までどおり（PWM2000・キックなし）。回転の前の「ため」も各振る舞いのまま。
- 判断は `Motion_Update()` の中で、回転中は毎 loop 行う（ジャイロは 25ms ごとに読むので、判断の細かさは約25ms）。

## 指示する角度（設計の固定値のまま）

| 使う所 | 角度 | 時間ベースの値（予備・上限） |
|---|---|---|
| ID15 少し回る（1回。最大12回） | 30° | 425ms（`TROUBLE_TURN_STEP_MS`。調整キー q・a の値） |
| ID25 横が近いときの向き変え／後退+その場回転 | 30° | 同上 |
| ID26 脱出の回転 | 60〜120°（今までどおりランダムに選ぶ） | 角度 × 13.0ms（`ROTATE_CONT_MS_PER_DEG`） |
| ID26 くり返し詰まったとき | 150〜210°（同上） | 同上 |
| キー 3・4 | 30° | 425ms |
| キー 7・8 | 90° | 1170ms |

- 角度に、新しくランダムな幅は付けない。
- 今日（2026-10-10）の時間ベースより回る量は減る（30°の指示で 約50° → 約30°、ID26 は 約1.8倍 → 設計どおり）。
  動きの印象は、書き込み2の5分うろうろで見る。

## 安全策（ここは厳しく守る）

| | 条件 | 動き |
|---|---|---|
| a. 回っていない | 回し始めから 300ms ごとに区切り、その 300ms で進んだ角度が 3° 未満（`GYRO_TURN_STALL_MS`・`GYRO_TURN_STALL_DEG`。どちらも【仮】） | 止める |
| b. 時間の上限 | 回し始めてから、時間ベースの値（×1.0）がたった | 止める |
| c-1. ジャイロが使えない（回し始め） | 状態が「測定中」でない、またはゼロ点が未補正 | その回は時間ベースで回す（今までと同じ動き） |
| c-2. 途中で失った | 回転中に状態が「測定中」でなくなった、または FIFO があふれた | その場で止める |
| d. 中断 | 持ち上げ・非常停止・振る舞いの交代・直進の指示 | 今までどおり止まる |

- a は、押さえられた・引っかかった・電池切れで回らない、のどれでも効く。回り始めの実測は 20〜70ms なので、300ms は約4倍の余裕。
  回転の途中で止められた場合は、区切りの関係で気づくまで最長 約600ms かかる。
  ジャイロの値が来なくなった場合も、角度が進まないので a で止まる。
- b の時間ベースの値は、2026-10-04 の遅い状態（約80dps）で「ちょうど設計の角度まで回る時間」。
  今日の速さ（約150dps）なら、角度に届くほうが先になる。届かずに b で止まる回が増えたら、電池が減った合図。
- 1回の回転の角度の上限は設けない（角度で止める判断と役割が重なるため）。
- 止めたあと、振る舞いは「回転が終わった」として次へ進む（今、時間で止まったときと同じ）。

## `t` に出すもの

止め方ごとの回数（起動からの累計。保存はしない）を、1行で出す。

```
[動き] 回転の止め方（起動から）：角度 12／時間の上限 0／回っていない 1／時間ベース 2／途中で失った 0／中断 0（いま回せば：ジャイロの角度で止める）
```

- 数えるのは、角度を指示して始めた回転（`Motion_StartTurnDeg()`）だけ。
  書き込み1ではキー 3・4・7・8、書き込み2からは ID15・ID25・ID26 も入る。
- 飛びは今までどおり、数えるだけで値は捨てない。

## シリアル出力（例）

```
[動き] その場回転 左 90°：ジャイロの角度で止めます（80°で止める。時間の上限 1170ms）
[動き] その場回転 左 停止（角度に届いた：80.6°。合計 702ms）
[ジャイロ] その場回転 左 702ms：+91.8°（止めるまで +80.6°・止めたあと +11.2°）最大 +239dps …
[動き] その場回転 右 30°：時間ベースで回します（425ms。ジャイロ：補正待ち）
[動き] その場回転 左 停止（回っていない：300ms で 0.4°。合計 300ms）
```

回った角度（止めるまで＋止めたあと）は、第1段階からある `[ジャイロ]` の回転の記録の行で見る。

## 使う部品・共通部品

- `src/core/gyro.*`：`Gyro_IsTurnUsable()`（測定中で、ゼロ点が補正済みか）を足すだけ。角度は既存の `Gyro_YawDeg()` の差で求める。
- `src/core/motion.*`：`Motion_StartTurnDeg()`、`Motion_Update()` の中の止める判断、止め方ごとの回数。
- `src/behaviors/debug_turn.*`・`src/main.cpp`：キー 3・4・7・8 が角度を渡す（書き込み1）。
- `src/behaviors/trouble.*`・`wander.*`・`stuck.*`：角度を渡し、時間を自分で数えるのをやめる（書き込み2）。
- 安全層・首の調停・障害物の判定は変えない。

## やらないこと（2026-10-10 の方針変更で外した）

- 惰性を角速度に比例させる式、止めた瞬間の角速度の記録。
- loop・区間・ログ出力の時間の記録、ログのためおき、回転中だけ 10ms ごとに読む、読む件数の上限の変更、シリアルの送信バッファ。
- 飛びの軸・大きさの記録、ゼロ点の観察・取り直し。
- 90°を10回くり返すキー（9・0）と合否の表、角度制御の入・切のキー（k）。
- 1回の回転の角度の上限。

loop を止めた時間の最大（約17〜18ms。角度にして約4°）と、飛びの原因は追わない。どちらも、この仕様のばらつきの中に収まる。

## 既知の限界（v1）

- 回る量には ±10°程度のばらつきが残る（惰性 6〜13°に対して固定の 10° を引くため。意図どおり）。
- 電池が減って回る速さが落ちると、惰性が小さくなり、目標より手前で止まる。さらに遅くなると、時間の上限で止まる。
- 車輪が空回りして車体が回らないとき、「回っていない」で止まるが、向きは変わっていない。振る舞い側は気づかない
  （ID15 は測り直してもう1回回る。ID25・ID26 は次の見回しに任せる）。
- ジャイロが実際より小さく読む故障では、時間の上限まで回る（今の時間ベースと同じ量）。
