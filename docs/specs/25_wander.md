# ID 25：うろうろ（v1）

カタログ：分類C／難易度 中／依存 7, 9, 15／位置づけ 2／実装順 2

最優先方針「障害物を避けながら部屋をうろうろする」の中核。
止まって見回し、歩き、また止まる、を繰り返す。

## きっかけ

常に発動している（車体レイヤーの既定の振る舞い）。
ID9「気づく」・ID15「障害物で困る」が発動していない間、これが動く。

## 動作の流れ

```
[ため] → [正面を測る] → [左を測る] → [右を測る] → [決める]
   ↑                                                  ↓
   │                                    （横が近ければ）[片側旋回で向きを変える]
   │                                                  ↓
[減速] ← [巡航（ランダム 1〜3秒）] ← [加速] ← [正面へ戻して安定を待つ]
```

1. **ため**：止まってから `WANDER_REST_MS`（800ms）待つ。いきなり首を振らない（設計原則3）。
2. **見回し**：首の使用権を「測距」で取り、正面 → 左 → 右 の順に測る。
   - 角度は正面 ±`WANDER_SCAN_PAN_DEG`（50°）。servo1 は 34° / 84° / 134°。
   - 各方向で、首が安定（`Neck_IsSteady`）してから `WANDER_SCAN_SAMPLES`（3回）測る。
   - その方向の値＝3回のうち**最も近い値**（危険側に倒す）。
     3回とも「エコーなし」「範囲外」なら `ULTRASONIC_MAX_CM`（80cm）＝空いている扱い。
3. **決める**：左右のうち近いほうが `WANDER_SIDE_NEAR_CM`（40cm）未満で、
   かつ反対側のほうが遠ければ、**反対側へ片側旋回**して向きを変える
   （`WANDER_AVOID_PIVOT_MS`＝500ms。浅い角度の壁への対策）。
   - 両方とも近い（通路のような場所）ときは向きを変えず、そのまま歩き出す。
   - 両方とも空いているときも向きを変えない。
4. **正面へ戻す**：首を正面・水平に戻し、使用権を返す。
   首が安定し、かつ測距の履歴が5回たまる（`Obstacle_IsReady`）まで待つ。
5. **歩く**：`MOTION_ACCEL_MS`（1600ms）で巡航速度まで上げ、
   `WANDER_RUN_MIN_MS`〜`WANDER_RUN_MAX_MS`（1000〜3000ms）のランダムな時間だけ巡航し、
   `MOTION_DECEL_MS`（1300ms）で止まる。加速・巡航・減速は ID9 と同じ。
6. 止まったら 1 に戻る。

途中で正面に障害物があると判定されたら、ID9（優先度30）が割り込んで即停止する。
このとき ID25 は `onStop` で目標速度を0にして待機し、ID9・ID15 が終わったら 1 から再開する。

### 歩き出す前に止める条件

次のどれかに当てはまる間は、5（歩く）に進まない。

- 正面に障害物がある（`Obstacle_IsBlocked`）… ID9 が発動するので、実際にはそちらに移る
- 首が正面・水平でない、または安定していない
- 測距の履歴が5回たまっていない
- 持ち上げられている（`Safety_IsLifted`）

## ID25 と ID9 の役割分担（ID9 の変更）

いまの ID9 は「停止→加速→巡航→減速」の走行ループ自身を持っている。
ID25 も同じループを持つため、**走行ループは ID25 に移し、ID9 は「気づいた瞬間の反応」だけにする**。

| | 変更前（スプリント1） | 変更後（スプリント2） |
|---|---|---|
| 走る・止まるの繰り返し | ID9 | **ID25** |
| 障害物に気づいて即停止・目を見開く・停止後の距離を出す | ID9 | ID9（据え置き） |
| 気づいたあとの後退・方向転換 | なし | **ID15** |

ID9 の優先度は、気づいている間だけ返す形にする（それ以外は0）。
`src/behaviors/notice.*` から `STATE_REST`/`ACCEL`/`CRUISE`/`DECEL` を削り、
`STATE_IDLE`（何もしない）と `STATE_NOTICED`（気づいた）だけにする。

## 回転（その場回転・片側旋回）※共通部品（#0）

実測（docs/measurements.md）で、回転・旋回は前進より大きなPWMでないと動き出さないが、
いちど回り出せば下げても回り続ける。そこで**キック（動き出し）→ 保持**の2段階で出す。

| 種類 | 左右の出力 | キック | 保持 | 使う場面 |
|---|---|---|---|---|
| その場回転 左 | 左輪 後退・右輪 前進 | 1150 | 1000 | 壁の前での方向転換（ID15） |
| その場回転 右 | 左輪 前進・右輪 後退 | 1150 | 1000 | 同上 |
| 片側旋回 左 | 左輪 停止・右輪 前進 | 1000 | 900 | 広い場所での向き変え（ID25） |
| 片側旋回 右 | 左輪 前進・右輪 停止 | 1000 | 900 | 同上 |

- キックを出す時間は `MOTOR_TURN_KICK_MS`（300ms。**未測定の仮値**）。
- 使い分けは catalog.md の ID25 のメモのとおり
  （壁の前ではその場回転＝角が壁に当たらない、広い場所では片側旋回＝柔らかく見える）。
- 値は正規化速度ではなく生のPWM。HAL に `Motor_DrivePwm(int leftPwm, int rightPwm)` を足し、
  `Motion_StartTurn` / `Motion_StopTurn` / `Motion_IsTurning` を motion.* に足す。
  モーターに書き込む場所を1つ（motion.*）に保つため、別モジュールにはしない。
- 回転を始めるとき・終えるときに `Obstacle_Reset()` を呼ぶ。
  車体が回っている間の測距は別の方向を見ているため、履歴に混ぜない。
- 回転中に `Motion_SetSpeed` を呼ぶと回転は取り消される（直進が優先）。

**左右の向きは実機で確認する。** 左＝M1・M2、右＝M3・M4 という測定ツールと同じ定義を前提に
しているが、実際にどちらへ回るかは目で見て確かめ、逆なら定義を入れ替える。

## 共通部品への変更（#0）

[common_obstacle.md](common_obstacle.md) の安全層の節にも反映してある。

### 1. 持ち上げたら即停止

- ライントラッキングが `111`（`SAFETY_LIFT_TRACK` = 0b111）になったら、その場でモーターを止める
  （床では `000`、持ち上げると `111` と実測）。回転中なら回転も取り消す。
- 復帰は慎重にする：`111` 以外が `SAFETY_LIFT_CLEAR_COUNT`（3回＝約300ms）続いたら解除。
  止めるのは1回で即座に、戻すのは3回続けて、とするのは、宙に浮いたまま車輪が回るのを避けるため。
  ライントラッキングは `TRACK_READ_INTERVAL_MS`（100ms）ごとに読むので、数えるのは
  「読んだ回数」で数える（毎ループ数えると数msで解除されてしまう）。
- **持ち上げを検知したら、動きの状態を確実に0に戻す。**
  `Motion_EmergencyStop()` で、なめらか加減速の目標速度・現在速度をどちらも0にし、
  回転中なら回転も取り消し、モーターに0を書き込む。
- **床に戻ったら、続きからではなく、やり直す。**
  持ち上げられている間、ID25・ID15 は状態を進めない。下ろされたら
  ID25 は「ため」から（見回しをやり直す）、ID15 は最初（後退）からやり直す。
  持ち上げられている間に向きも場所も変わっているので、持ち上げ前の測距値や
  「あと何回回れば一周か」を引き継がない。

### 2. 障害物での即停止は「前進」と「片側旋回」だけを止める

いまの安全層は、障害物があれば動きをすべて止める。これだと ID15 が壁の前で
立て直せない（後退も回転もできない）ため、次のように分ける。

| 動き | 障害物があるとき | 理由 |
|---|---|---|
| 前進 | **止める** | 障害物に近づく |
| 片側旋回 | **止める** | 片輪が前に出るので、車体が前へふくらむ |
| 後退 | 止めない | 障害物から離れる |
| その場回転 | 止めない | 中心が動かないので、角が壁に当たらない |

持ち上げの停止は、これと関係なくすべての動きを止める。

### 3. 回転角を測るためのデバッグキー（本体のシリアル）

回転1ステップで何度回るかは未測定で、`WANDER_AVOID_PIVOT_MS` と `TROUBLE_MAX_STEPS` を
決めるのに要る。本体のシリアル（115200bps）から1文字で、1ステップだけ回せるようにする。

| キー | 動き | 時間 |
|---|---|---|
| `3` | その場回転 左 | `TROUBLE_TURN_STEP_MS`（500ms） |
| `4` | その場回転 右 | 同上 |
| `5` | 片側旋回 左 | `WANDER_AVOID_PIVOT_MS`（500ms） |
| `6` | 片側旋回 右 | 同上 |
| `?` | キーの一覧を表示 | ― |

キーの割り当ては tools/measure_m2 のモードと同じにする（同じ操作で測れるようにするため）。
時間は実際に振る舞いが使う設定値そのままで、デバッグ用の別の値は持たない。

**受け付ける条件**（ひとつでも欠けたら、理由を1行出して無視する）：

- 車体が止まっている（目標速度・現在速度がどちらも0で、回転していない）
- ID15「障害物で困る」が動いていない
- 持ち上げられていない

車体レイヤーの振る舞い（優先度 `PRIORITY_DEBUG_TURN` = 50）として作り、
ID25・ID9・ID15 のどれよりも優先する。1ステップ終わったら優先度を0に落として、
ふだんの振る舞いに戻す。

### 4. うろうろの一時停止（`p` キー）

回転角を落ち着いて測るため、ID25 と ID15 を止められるようにする（`src/core/debug_pause.*`）。

| キー | 動き |
|---|---|
| `p` | 一時停止 ⇔ 再開を切り替える |

- **一時停止中**：ID25 と ID15 の優先度が0になり、車体はその場で止まったままになる
  （動いていたら、なめらかに減速して止まる。首は向いていた向きのまま）。
  まばたき（目レイヤー）は続く。ID9 の気づく反応は、障害物があれば動く（止まっているだけなので害はない）。
- **一時停止中も 3〜6 を受け付ける**（受け付ける条件は変わらない。止まっているときだけ）。
- **再開**：ID25 は「ため」から始める。ID15 は、塞がっていれば最初（後退）からやり直す。
- **起動直後**：`DEBUG_START_PAUSED`（config.h。既定 0）を 1 にすると、一時停止の状態から始める。
  0 なら今までどおり、起動したらすぐうろうろを始める。
- 状態行に「一時停止中」を出す。`?` のキー一覧にも現在の状態を出す。

## 優先度

| レイヤー | 振る舞い | 優先度 | 発動する条件 |
|---|---|---|---|
| 車体 | デバッグ回転（`3`〜`6`） | 50 | キーを受け付けたときだけ。1ステップで終わる |
| 車体 | 障害物で困る（ID15） | 40 | 気づいて止まったあと、正面が塞がっている間 |
| 車体 | 気づく（ID9） | 30 | 障害物がある、または気づいた直後の反応中 |
| 車体 | **うろうろ（ID25）** | **20** | 常に（既定の振る舞い） |
| 目 | 気づく（見開く）（ID9） | 30 | 気づいてから `NOTICE_WIDE_MS` の間 |
| 目 | まばたき（ID1） | 10 | 常に |

車体レイヤー内の大小だけが意味を持つ（目レイヤーとは別に比べる）。
`PRIORITY_NOTICE` は 20 → 30 に変える。

## 初期値の根拠

- **見回しの角度 50°**：servo1 の可動範囲は 20〜140°、正面 84° なので、
  左右対称に取れるのは ±56° まで。実測の安定時間は ±55° で最長160ms、
  式（60＋角度×2）では 50° → 160ms で収まる。
  浅い角度の壁ほど大きく振ったほうが正面から見られる（入射角が浅いと測れない）ので、
  対称に取れる範囲でなるべく大きくした。
- **横が近い＝40cm**：停止閾値 36cm より少し広い。
  横を通り過ぎるだけなら 36cm でも当たらないが、浅い角度の壁は
  進むほど寄ってくるので、気持ち広めに見る。
- **巡航 1〜3秒**：ID9 の 1500ms を中心に、前後に振った。
  加速1.6秒＋減速1.3秒が付くので、1回の移動は 3.9〜5.9秒。
  実測の巡航速度 41.1cm/s から、進む距離はおよそ 60〜140cm。
- **片側旋回 500ms**：1回の旋回で向きが変わりすぎないように短くした。
  **何度回るかは未測定**。実機で測って measurements.md に記録し、値を詰める。

### 観察項目（合否には含めない）

- **壁と平行に進むとき、横の壁を見落とすか。**
  横の判定 `WANDER_SIDE_NEAR_CM`（40cm）は、首を50°振って斜めに測った距離なので、
  壁が進行方向と平行なら、横方向の実距離は 40 × sin50° ≒ **31cm** に当たる。
  つまり横に 31〜40cm の壁は「近い」と判定されない。
  壁に沿って歩かせて、どのくらい寄ると避けるようになるかを見る。
  見落とすようなら `WANDER_SIDE_NEAR_CM` を上げるか、見回しの角度を変える。
- 片側旋回・その場回転が1ステップで何度回るか（デバッグキー `3`〜`6` で測る）。
