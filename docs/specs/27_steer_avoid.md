# ID 27：進みながらよける（v1・段階2 の最小の形）

カタログ：分類C／難易度 高／依存 25, ジャイロ, 3.6-3 段2／ブランチ id27

前進中、端の列に写った物を、止まらずに反対側へ少し曲がってよける。
狙いは止まる回数を減らすこと。今の「止まって困る」は残し、よけられないときはそちらへ任せる。

**v1 の範囲**：内側フリーの曲がり 1 種類だけ。ブレーキは使わない。
**次の候補（今は作らない）**：フリーで足りなかったら内側をブレーキにする。段階1 では 0.3秒で 15〜19°（フリーは約 6°）向きを変えられるが、最初の約 0.2秒に 60〜84°/秒の急な曲がりが出る。

## きっかけ

次をすべて満たしたとき。

1. 前進中（ID25 うろうろの巡航）で、首は走行姿勢のまま安定している。
2. 端の列（左 c0〜c1 または 右 c6〜c7）の r0〜r4 のマスのうち、次をすべて満たす物が写っている。
   - 前後の距離が、止まる距離（`TOF_STOP_MM` 380mm）より遠く、`STEER_TRIGGER_MM`【仮】より近い。
   - 高さが `TOF_HEAD_CLEAR_MM`（160mm）未満（テーブルの天板などで曲がらない）。
   - 車体の中心からの横の位置が `STEER_SIDE_MAX_MM`【仮】以内（首が右へ 8° 向いていて、同じ距離でも横の位置が左右で違うため。700mm で c0 は左 163mm、c7 は右 349mm）。
3. 中央の列の物では使わない：その端の列の物が、中央の列（c3〜c4）の最も近い物より `STEER_EDGE_LEAD_MM`【仮】以上近いときだけ使う（斜めの壁は中央の列にも少し遠い距離で写るので、「写ったら使わない」にはしない。止まる枚で見ると 13回のうち正面の壁の 7番だけが外れる）。
4. 上の物が `STEER_NEAR_FRAMES`（2枚）続けて写り、`STEER_SHRINK_WINDOW_MS`（0.2秒）で `STEER_SHRINK_MM`【仮】以上縮んでいる（平行な壁と、1枚だけ飛んだ値で曲がらない）。使える時間が約 1秒しかないので短くした。3.0秒の記録を見て詰め直す。
5. 反対側の横に余裕がある（安全の条件 ①）。
6. 前回の曲がりから `STEER_COOLDOWN_MS`【仮】たっている。

## 動作の流れ

1. きっかけを満たしたら、向きと、その時点の向き（ジャイロ）・写っていた距離を覚える。
2. 反対側へ進みながら曲がる。内側は PWM 0（フリー）、外側は `STEER_OUTER_PWM`。段階1 の `Motion_StartArc`（前進の一種）を使う。
3. 次のどれかで曲がるのをやめ、巡航へ戻す。
   - 向きが `STEER_MAX_DEG` 変わった。
   - `STEER_MAX_MS` たった（ジャイロの異常に備える上限）。
4. そのあとは今までどおり歩く。よけきれなかったときは、通路の中の物で止まる判断に任せる。ID27 から止める道は作らない。
5. 曲がっている間も、止まる判断が必ず優先する。通路の中が止まる距離まで近づいたら、今までどおり止まって困るへ。

## 安全の条件

1. **反対側の横に余裕があるときだけ曲がる。** 反対側の端の列の r0〜r4 で、最も近い物が `STEER_OPPOSITE_CLEAR_MM`【仮】より遠いこと。測れないマスが多くて写らないときは、余裕ありとしない。
2. **曲がると、よけている物は視野の外へ出る。** 写らなくなったことを「よけきれた」の根拠にしない。よけきれたかは、ジャイロの角度と最後に写った距離で判断する。
3. **曲がるとき、車体の後ろはよけている側へ振れる（後ろにセンサーはない）。** 計算は下の「後ろの角の振れ」。
4. ジャイロが測定中でないときは曲がらない。
5. 持ち上げの安全層と ToF の途切れ・非常停止は、今までどおり働く（前進の一種なので外れない）。

### 後ろの角の振れ（安全の条件 ③）

寸法：回転の中心から後ろの端まで 155mm（実測）、半幅 75mm。よけている側の後ろの角が、車体の中心に比べて横にどれだけ振れるかを、向きの変化 θ で計算する。

振れ ＝ 155 × sin θ ＋ 75 × cos θ − 75

| θ | 振れ（車体の中心に比べて） |
|---|---|
| 15° | 約 38mm |
| 30°（上限） | 約 67mm |

- 回転の中心を「前後は 155mm の基準の点」として、そこを中心に向きだけが変わるとした計算。内側フリーのときに実際に回る中心がどこかは【未確認】。
- **車体の中心が曲がる方向へ動く分の打ち消しは【未確認】。** 曲がる間の前に進む速さが測れていないため。曲がる半径を R とすると、θ の間に中心は R × (1 − cos θ) だけよけている側から離れるが、R が分からないので差し引かない。上の値は打ち消しを入れない、大きいほうの値。
- **約 67mm は、通路の余裕（片側 20mm【仮】）より大きい。**

**危ない場面：** よけている物そのものより、前へ進むうちに視野の外へ出た、車体の横や後ろの物。センサーでは見えない。
- 壁に沿って歩いているときに、前の物をよけて壁から離れる向きへ曲がると、後ろの角が反対の壁へ振れる。ただし反対側は余裕を確かめている。問題は、よけている側に、すでに横へ来ている物がある場合（例：すり抜け中のいすの脚、箱の角）。
- 狭い場所で、横に物が並んでいるとき。車体の横の余裕が約 67mm より小さいと、当たる可能性がある。
- 止まって後ろの角が当たっても、後ろにセンサーがないので気づけない。詰まりの見張りで見つかるかは【未確認】。

**対策の案（実装しない。実機で接触が出たら検討する）：**
1. 横に沿った壁が写っているときは曲がらない（よけている側の端の列に、距離が縮まない物が続けて写っていた直後は使わない）。
2. よけている側で、直前の数枚の間に端の列を通り過ぎた物があれば曲がらない（枚の記録から、近い物が視野から外へ出たことを見る）。
3. 角度の上限を下げる（15° で振れは約 38mm。ただし、よけられる量も減る）。
4. 曲がる間の速さを測り、打ち消しの分を確かめてから線を決める。

## 試験で数えるもの（t に出す）

- ID27 で曲がった回数（左右別）
- よけきれた回数（曲がり終えてから `STEER_CLEARED_MS` の間、止まらなかった回）
- 曲がったあとに止まった回数
- 曲がり終えてから次に止まるまでの時間（平均・最小）
- 止まったあとの困るの時間（平均・最大）
- 前進 1秒あたりの止まる回数（合否に使う）
- 曲がった回ごとの記録（直近 18回）：左右、きっかけになった列と距離（＝最初に写った距離）、曲がった角度と時間、最後に写った距離、結果（よけきれた・止まった・交代・続けて曲がった・打ち切り・まだ決まっていない）、交代した相手
- 比べるために今も出ているもの：止まった回数（参考）、前進の合計、前端の隙間の最小、横の余裕の最小
- 止まる前の記録（t の食い違いの記録）：3.0秒。1枚ごとに端の列・中央の列（c3〜c4）の距離と、止まっていた枚か動いていた枚か

## 完了条件

- 動作：5分の試験で、次をすべて満たす。
  - 前進 1秒あたりの止まる回数が 2割以上減る（2026-11-02 の 0.34回/秒 → 0.27回/秒以下）。止まった回数（今回 31回）は参考として並べて記録する。
  - 接触 0。
  - 前端の隙間の最小 5cm 以上【仮】（外側 1000 で速くなり、止まるまでの距離が延びる心配があるため）。
- 愛らしさの観点：止まらずにすっとよけて、そのまま歩き続ける。
- やめどき：実装と5分は 2セッションまで。満たさなければブランチごと捨てる。

## 心配な点（未確認）

- **曲がる間の速さと止まる距離。** 外側 1000 は巡航（726）より強く、曲がる間の前に進む速さは測れていない（段階1 の速さの記録は使えなかった）。止まるまでの距離が今より延びるかもしれない。今の前端の隙間の最小は 88mm。試験で必ず見る。
- **出力の急な変化。** `Motion_StartArc` は 726→1000 に一度に変える。「急発進・急停止をしない」との関係を実機で見る。
- **加速中の扱い。** 段階1 の測定は直進 0.8秒のあと。うろうろの加速は 1.6秒で、1回に歩く時間は平均約 2.9秒（前進 90.4秒 ÷ 31回）なので、きっかけが巡航に限られると機会が減るかもしれない。
- **うろうろへの戻り方。** ID27 が交代したあと、うろうろが止まらずに巡航へ戻れるかは、実装のときに確かめる。
