セッションを開始します。次の手順を行ってください。

1. `CLAUDE.md` と `docs/handoff.md` を読む。
2. `git status` と直近のコミット（`git log --oneline -5`）を見る。
   未コミットの変更や、未プッシュのコミット（`git log origin/main..HEAD --oneline`）があれば知らせる。
3. 次の3点を、日本語で短く要約する。
   - 現在地
   - 次にやること
   - 今日の作業に関係する未解決の点
4. 要約したら止まり、私の指示を待つ。

決まり
- コードの変更・ビルド・書き込み（upload）はしない。
- `docs/notes.md`（常設の注意書き）は毎回は読まない。作業に必要になったときに読む
  （書き込み・シリアル・デバッグキー・試験の集計などを扱うとき）。
- 着手する ID が決まったら、その時点で `docs/specs/` の該当ミニ仕様と `docs/catalog.md` を読む（ここでは読まない）。
